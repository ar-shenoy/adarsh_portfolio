    AI-NPC Interaction Engine

    A modular Python engine simulating intelligent NPC interactions using OOP and ML.This prototype is built within 48 hrs to demonstrate interest and capabilities for Scopely's AI Intern role.Integrates intent classification, emotion-aware responses, and battle mechanics.

    Features

  • AI Dialogue Handling: NPCs interpret player messages using ML-based intent recognition.
  • Emotion-Based Behavior: Characters adjust combat and responses based on mood.
  • Hero vs Villain Battles: Turn-based battle simulation with healing, damage scaling, and emotion dynamics.
  • Custom NPC Loading: Load detailed NPCs from Parquet files with mood, responses, and biography.
  • Intent Classification Model : Trained using TF-IDF + Logistic Regression for simple NLP-based predictions.
  • Self-contained Testing Suite: Simulated scenarios in `main.py` to validate character behavior and intent handling.

    Limitations

    Current intent classifier(ML model) achieves ~59% accuracy due to limited dataset quality and size. With improved data, model performance and AI-NPC realism can significantly increase.
