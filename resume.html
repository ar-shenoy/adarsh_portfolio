Projects

cerebAI

    cerebAI is a deployed AI-based stroke detection system built using the ConvNeXt Base architecture in PyTorch to classify CT scans into No Stroke, Ischemic, or Hemorrhagic. It achieved state-of-the-art diagnostic performance with a mean IoU of 0.9843 and a weighted F1 Score of 0.9805, confirming high reliability. To ensure explainability, Integrated Gradients (Captum) was implemented for pixel-level attributions, highlighting pathology regions and providing transparent clinical insights. The pipeline supports professional DICOM preprocessing, including Hounsfield Unit conversion and windowing, as well as compatibility with JPG, JPEG, and PNG formats. Deployed on Hugging Face Spaces via Streamlit SDK, the system delivers rapid, real-time results making it suitable for clinical prototyping and medical decision support.

LunarisAI

    LunarisAI is a menstrual cycle prediction assistant that uses machine learning to estimate the next period date based on personal health and cycle data. Built with RF Regressor and deployed via Streamlit for user-friendly accessibility., LunarisAI adapts to user inputs like stress, PCOS, and birth control usage to provide personalized predictions with uncertainty windows.
